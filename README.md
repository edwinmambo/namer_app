# ✨🚀 Namer App (Flutter)

A polished Flutter learning app that generates cool-sounding startup names 🎲, allows users to ❤️ favorite them, and review ⭐ saved names on a separate screen — all wrapped in a responsive, Material Design UI 📱📐.

This project was built while learning Flutter fundamentals, following official and community resources.

## ✨ Features

- 🎲 Generate random, cool-sounding startup names
  _Examples: newstay, lightstream, mainbrake, graypine_
- ⏭️ Instantly fetch the next name
- ❤️ Favorite / unfavorite name suggestions
- 📜 View all favorite names on a dedicated page
- 📱 Responsive layout for different screen sizes
- 🎨 Clean Material Design UI
